## TextMate Grammar

A TextMate grammar is available for LPML syntax highlighting:

**[lpml.tmLanguage.json](/grammars/lpml/lpml.tmLanguage.json)**

This grammar can be used in any editor that supports TextMate grammars, including VS Code, Sublime Text, and others.
